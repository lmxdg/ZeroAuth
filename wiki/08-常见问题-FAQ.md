# 常见问题 FAQ

### 安装类

**Q: 安装向导提示 PHP 版本不满足？**
系统要求 PHP 8.0 ~ 8.2。宝塔面板可在「网站 → PHP 版本」切换。

**Q: 提示根目录不可写？**
安装需在根目录生成 `config.php`、`install.lock` 和自定义后台目录，请确认网站根目录对运行用户可写（`runtime/` 也需可写）。

**Q: MySQL 8.0 能用吗？**
建表 SQL 兼容 MySQL 5.6~5.7 且未使用 8.0 特有语法，8.0 一般可正常运行，但官方验证环境为 5.6~5.7。

### 验证码类

**Q: 验证码显示 1×1 空白图？**
V2.0.0（内核 1.5.0）已彻底修复：GD 产物尺寸校验 + 自动 SVG 兜底 + 全链路 no-store 防缓存。若覆盖升级后仍出现：① 强刷浏览器 Ctrl+F5；② 确认新版 `captcha.php` 已覆盖到**实际后台目录**（自定义后台目录的站点需同步覆盖 `admin/` 内容）。

**Q: 服务器没有 GD 扩展会怎样？**
自动降级为 SVG 数字验证码，功能始终可用；但建议安装 GD 以获得图形验证码。

### API / 授权类

**Q: 返回 `signature_upgrade_required`？**
密钥（不绑定站点）授权的新站点首次绑定必须使用 v2 签名，说明 SDK 仍是 v1 旧协议，请升级 SDK。

**Q: 返回 `site_limit_exceeded`？**
卡密绑定的站点数已达 `max_devices` 上限，请在后台解绑旧站点后再验证。

**Q: 域名查询不到授权？**
确认域名已绑定授权（后台卡密域名绑定管理）；查询时系统会自动归一化（小写、去 www），泛域名授权用 `*.example.com` 形式维护。

**Q: v1 和 v2 签名怎么选？**
新接入一律 v2（HMAC-SHA256，防重放更完善）；v1 仅用于兼容旧 SDK，且新站点绑定会被强制要求升级。

### 支付类

**Q: 支付后订单未变更为已支付？**
检查支付插件配置与回调地址可达性（`https://你的域名/api/pay_callback.php`）；部分接口/网关需在支付平台配置白名单；查看后台订单管理与邮件日志排查。

### 升级类

**Q: 覆盖升级要注意什么？**
保留 `runtime/`、`config.php`、`install.lock`；自定义后台目录的站点务必将新版 `admin/` 同步覆盖到实际后台目录；数据库结构自动迁移无需手动 SQL。

### 其他

**Q: 忘记管理员密码？**
使用后台登录页「忘记密码」通过 SMTP 邮件找回（需先在「系统配置」中配置好 SMTP）。

**Q: 如何自定义首页？**
开发 `template` 类主题插件放入 `plugin/` 并启用，见[主题开发指南](06-主题开发指南)。
