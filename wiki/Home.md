# ZeroAuth Wiki — 软件授权 & 域名授权管理系统

> 原作者：APE开发项目组-玄猿工坊 · 修改维护：MEMZ-LMXDG · 官方 QQ 群：1125324975

欢迎来到 ZeroAuth 官方 Wiki。ZeroAuth 是一套基于 PHP 8.0~8.2 + MySQL 的多角色软件授权管理系统，支持**卡密授权**与**域名授权**，内置用户中心、代理商体系、管理后台三端，以及签名校验 API、SDK 导出、支付充值、插件与主题扩展机制。

## ⚡ 快速开始

1. 准备 PHP 8.0~8.2 环境与 MySQL 数据库 → [环境要求](02-环境要求与安装)
2. 上传代码，访问 `https://你的域名/install/` 按向导安装
3. 登录后台，创建应用（获取 AppKey / AppSecret）
4. 在后台生成卡密或为域名开通授权
5. 在你的软件 / 网站中集成授权校验 API → [API 文档](04-API-接口文档)
