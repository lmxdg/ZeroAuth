# 功能总览

## 管理后台（`admin/`）

| 模块 | 功能 |
|---|---|
| 仪表盘 | 授权 / 订单 / 用户核心指标总览、世界地图统计（`world_map.php` + `assets/geo/`） |
| 应用管理 | 多应用 CRUD、AppKey/AppSecret、售价、授权类型与方式、设备上限、回调 URL |
| 版本管理 | 应用版本与安装包管理，配套版本检查 / 更新包下载 API |
| 卡密管理 | 批量生成、列表检索、状态封禁、授权概览、域名绑定管理 |
| 订单管理 | 订单列表、支付状态、财务流水 |
| 用户管理 | 用户 / 代理商账号、等级管理（等级折扣与赠送余额）、实名审核 |
| 风控 | IP 封禁、多维黑名单（设备码 / 卡密 / 域名）、防盗版追踪、验证日志、告警中心 |
| 系统 | 系统配置（站点信息、SMTP、验证与真实 IP、密钥下发开关等）、SDK 管理与导出、云变量管理、邮件日志、审计日志 |
| 应用商店 | 插件 / 主题的安装、启用、配置（支持「行为验证」「第三方登录」等分类筛选） |
| 其他 | 工单处理、折扣活动管理、关于系统、管理员资料 |

## 代理商中心（`agent/`）

- **等级折扣**：代理商等级体系，等级折扣覆盖独立折扣（0.01~1.00），等级可赠送余额
- **邀请体系**：代理商邀请码，名下用户注册绑定时填写，形成上下级归属
- **进销存**：按折扣价购买卡密、管理名下用户、卡密分发
- **财务**：余额、消费流水、提现申请
- **工单**：与平台管理员的工单沟通

## 用户中心（`user/`）

- 注册登录（支持验证码、第三方登录、找回密码）
- **实名认证**：提交姓名与身份证号（身份证号加密存储），后台审核
- **购买**：已上架应用按售价购买授权，支持余额支付与在线支付
- **卡密兑换**：`redeem.php` 卡密开通授权
- **我的授权**：查看授权状态、有效期、剩余次数
- **财务**：余额、订单记录
- **工单**：提交与跟进工单

## 公开首页（`index.php`）

- **域名授权公开查询**：访客输入域名，展示授权状态（正常 / 过期 / 封禁 / 未授权）、授权类型、所属应用、有效期或剩余次数
- 查询限流：每 IP 每分钟 30 次
- 首页外观由 `template` 类主题插件按 `sort` 优先级自动选择，未启用任何主题时显示维护页
- 页脚展示官方 QQ 群与版权署名

## 验证码体系

- GD 主路径：132×44 PNG（干扰弧线/折线/噪点 + 随机倾角字符），无字体环境回退 `imagechar`
- 自动降级：GD 缺失或绘制产物异常（如历史 1×1 空白图）自动改走 SVG 数字验证码
- 全链路防缓存：`no-store` 响应头 + 版本参数防缓存 URL
- 可选增强：极验 4.0、Cloudflare Turnstile 插件（启用时优先级最高）
