# 系统简介

## 定位

ZeroAuth（产品版本 2.0.0，内核 1.5.0）是面向商业软件作者与发行方的**软件授权 & 域名授权管理系统**，可用于：

- PHP / Web 应用的**域名授权**（防站点被盗部署）
- 桌面软件 / 脚本的**卡密授权**（激活码、计次授权）
- 通过代理商体系进行**多级分销**

## 核心能力

### 多应用隔离
每个应用拥有独立的 AppID / AppKey / AppSecret，可分别配置售价、支持的授权类型与授权方式、默认设备上限、授权验证回调 URL。卡密、订单、验证日志均按应用隔离。

### 授权模型
- **授权类型**：1 限时授权（含生效期与到期时间）、2 计次授权（总次数 / 已用次数）、3 永久授权
- **授权方式**（目标绑定）：1 单域名、2 泛域名（支持 `*.example.com` 匹配）、3 IP 授权、4 密钥授权（仅卡密核验，不绑定站点）
- **设备（站点）绑定**：域名/IP 授权按 `sha256(appKey|licenseKey|target)` 生成站点唯一标识，支持上限控制与解绑重绑

### 授权验证 API
`api/license/verify` 支持 v1（MD5 兼容旧 SDK）与 v2（HMAC-SHA256）两种签名协议，验证通过自动完成站点绑定、计次扣减；命中黑名单返回 `blacklisted` 并触发告警。详见 [API 接口文档](04-API-接口文档)。

### 三端体系
| 端 | 目录 | 面向 |
|---|---|---|
| 管理后台 | `admin/` | 平台管理员 |
| 代理商中心 | `agent/` | 授权分销商 |
| 用户中心 | `user/` | 终端买家 |

公开首页（`index.php`）提供域名授权状态**公开查询**，访客输入域名即可看到授权类型、所属应用、有效期与剩余次数。

### 支付与增值
内置支付宝 / 微信 / 易支付 / 余额支付四种支付插件，订单状态查询与支付回调 API 齐全；支持优惠折扣活动、财务流水、代理商提现、SMTP 邮件通知（场景化模板 + 发送日志）。

### 扩展机制
文件驱动插件系统：`plugin/` 目录放入即被识别，后台「应用商店」启用配置。分类涵盖支付、验证码、第三方登录、实名认证与首页主题。

## 技术栈

- **后端**：原生 PHP 8.0~8.2（无框架依赖），PDO MySQL
- **数据库**：MySQL 5.6~5.7 兼容，27 张表，存量库由 `core/schema_upgrade.php` 幂等自愈迁移
- **前端**：原生 JS + 内置静态资源（含世界/中国地理数据用于统计地图）
- **部署**：单站点部署，`runtime/` 与根目录可写即可

## 目录结构

```
ZeroAuth/
├── admin/            # 管理后台
├── agent/            # 代理商中心
├── user/             # 用户中心
├── api/              # 授权 / 云变量 / 支付回调 / 版本更新 API
├── core/             # 内核：引导、安全、支付、邮件、验证码、插件系统
├── plugin/           # 插件与主题
├── install/          # 安装向导与全量建表 SQL
├── assets/           # 静态资源
├── docs/             # 开发文档与更新说明
├── runtime/          # 运行时日志与缓存（需可写）
├── uploads/          # 上传目录（需可写）
└── index.php         # 公开首页（域名授权查询）
```
