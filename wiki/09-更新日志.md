# 更新日志

> 详细说明见源码 `docs/更新说明.md`

## V2.0.0（内核 1.5.0）

**修复**
- 彻底解决 open_basedir（宝塔等环境）下验证码乱码 / 空白问题：字体探测加 `@` 抑制、验证码入口关闭错误回显、PNG/SVG 输出前清空输出缓冲并附带精确 `Content-Length`
- 验证码主路径全面改为 GD 生成（132×44 PNG，干扰线 + 噪点 + 随机倾角，无字体回退 `imagechar`），产物尺寸校验，任何退化自动走 SVG 兜底

**改进**
- 验证码全部响应增加 `no-store` / `Pragma` / `Expires` 头 + 精确 `Content-Length`，浏览器、CDN、反代不再缓存
- 全站 17 处验证码 `<img>` 与 JS 刷新地址追加 `?v=内核版本&t=时间戳` 双参数防缓存

## V1.1.0（内核 1.1.3）

**品牌与界面**
- 系统更名 ZeroAuth，全局 Logo / favicon 更新（后台可覆盖自定义）
- 后台新增「关于系统」页面；安装向导换新，`config.php` / `install.lock` 写入版权信息

**修复**
- 修复前台登录验证码加载失败；CDN / 反代场景验证码限流不再按代理 IP 误伤
- 验证码限流阈值 30 → 60 次/分钟；无 GD 自动降级 SVG，限流返回占位图；前端自动重试 + 时间戳防缓存

**新增**
- 真实 IP 获取（CF-Connecting-IP → X-Real-IP → X-Forwarded-For，过滤内网地址，可关闭）
- Cloudflare Turnstile 验证插件（全验证场景生效，优先级最高）
- 极验 4.0 拆分为独立插件，旧配置自动兼容迁移
- 注册验证码开关（默认开启）
- 彩虹聚合登录插件：16 种登录方式、自动注册、一键绑定、独立绑定表 `rainbow_bind`
- 应用商店「行为验证」「第三方登录」分类筛选
- 首页模板按 `template` 类插件 `sort` 优先级自动选择
- 新增 `docs/` 目录（插件开发 / 主题开发文档）

## V1.0.0

首个整合版本：多角色（管理员 / 代理商 / 用户）软件授权 & 域名授权管理，27 张表全量结构，v16~v18 增量迁移并入全量建表 SQL，存量库由 `core/schema_upgrade.php` 幂等自愈迁移。
