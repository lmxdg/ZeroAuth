# 主题开发指南

> 完整版见源码 `docs/主题开发文档.md`

## 主题机制

首页主题本质上是 `cat = 'template'` 的插件。系统在 `index.php` 中扫描全部 `template` 类插件，按 `sort` 数值**从小到大**取第一个已启用的主题渲染公开首页；没有任何启用主题时显示「站点维护中」页面。

## 主题结构

```
plugin/你的主题目录/
├── Plugin.php      ← 元数据：'cat' => 'template'
├── icon.svg
└── home.php        ← 首页渲染入口（必需）
```

```php
<?php
// Plugin.php
return [
    'code' => 'mytheme',
    'name' => '我的主题',
    'cat'  => 'template',
    'description' => '自定义首页主题',
    'version' => '1.0.0',
    'author'  => '你的名字',
    'sort'    => 100,        // 数值越小优先级越高
];
```

## home.php 可用变量

| 变量 | 说明 |
|---|---|
| `$tplCode` / `$tplDir` | 当前主题 code 与目录名 |
| `$query_domain` | 用户本次查询的域名（`?q=` 参数，已 trim） |
| `$result` | 查询结果数组或 null：`['level' => 'ok\|warn\|bad', 'main' => '主标题', 'sub' => '详情']` |
| `$admin_dir` | 后台目录名（用于登录入口链接） |

`level` 含义：`ok` 已授权状态正常、`warn` 已过期 / 次数用尽、`bad` 未授权 / 已封禁 / 格式错误 / 限流。

## 最小示例

```php
<?php // plugin/mytheme/home.php
declare(strict_types=1);
?>
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>域名授权查询</title>
</head>
<body>
  <h1>域名授权查询</h1>
  <form method="get">
    <input type="text" name="q" value="<?= e($query_domain) ?>" placeholder="example.com">
    <button type="submit">查询</button>
  </form>
  <?php if ($result): ?>
    <p class="<?= e($result['level']) ?>">
      <strong><?= e($result['main']) ?></strong><br><?= e($result['sub']) ?>
    </p>
  <?php endif; ?>
</body>
</html>
```

> 输出变量务必使用 `e()` 转义，防止 XSS。

## 切换主题

后台「应用商店」中启用目标主题即可；多个主题同时启用时按 `sort` 优先级生效。
