# 环境要求与安装

## 环境要求

| 项目 | 要求 |
|---|---|
| PHP | **8.0 ~ 8.2**（安装向导强制检测） |
| 必需扩展 | PDO、PDO MySQL、JSON、MBString |
| 推荐扩展 | cURL（支付/邮件）、Zip（SDK 打包下载）、OpenSSL（安全签名）、GD（验证码） |
| 数据库 | MySQL 5.6 ~ 5.7 兼容（不使用 8.0 特有语法） |
| 目录权限 | `runtime/` 可写；**网站根目录可写**（需生成 `config.php`、`install.lock` 及自定义后台目录） |

> 宝塔等开启了 `open_basedir` 的环境已适配：验证码渲染会抑制路径探测 Warning，输出纯净 PNG 二进制。

## 全新安装

1. **上传代码**：将全部文件上传至网站根目录（如 `/www/wwwroot/auth/`），建议运行目录指向站点根目录；
2. **创建数据库**：在 MySQL 中新建一个空数据库（utf8mb4）；
3. **运行安装向导**：浏览器访问 `https://你的域名/install/`，依次完成：
   - 环境检测（PHP 版本、扩展、目录可写）
   - 数据库连接配置（向导自动执行 `install/schema.sql` 全量建表，共 27 张表）
   - 管理员账号创建
4. **自定义后台目录**：安装时可将 `admin/` 复制为自定义后台目录（如 `zaadmin/`），提升安全性；
5. **进入后台**：访问 `https://你的域名/你的后台目录/` 登录；
6. **启用插件**：后台「应用商店」按需启用支付（alipay / wechat / epay / balance）、行为验证（geetest / turnstile）、第三方登录（rainbow）与首页主题（default / tpl_v1 / tpl_v2）。

安装完成后系统根目录会生成 `config.php`（含数据库与版权信息）与 `install.lock`（安装锁），**请勿删除或提交到公开仓库**。

## 覆盖升级

1. 覆盖上传全部新版本文件；
2. **保留** `runtime/`、`config.php`、`install.lock`；
3. ⚠️ **重要**：安装时自定义了后台目录的站点，请将新版 `admin/` 目录内的文件**同步覆盖到实际后台目录**（尤其 `captcha.php`），否则后台仍运行旧代码；
4. 存量数据库结构由 `core/schema_upgrade.php` 自动幂等迁移，无需手工执行 SQL；
5. 升级后建议强刷浏览器（Ctrl+F5），并到「应用商店」确认插件状态。

## 卸载 / 重装

删除根目录 `config.php` 与 `install.lock` 后重新访问 `install/` 即可重装（数据库表不会被自动删除，需手动清理）。
