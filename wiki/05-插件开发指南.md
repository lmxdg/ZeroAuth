# 插件开发指南

> 完整版见源码 `docs/插件开发文档.md`

## 插件机制

ZeroAuth 采用**文件驱动的插件系统**：系统启动时自动扫描 `/plugin/*/Plugin.php`，每个目录即一个插件，放入即被识别，再到后台「应用商店」启用。

```
网站根目录/
└── plugin/
    └── 你的插件目录/       ← 目录名建议与 code 一致（小写字母数字下划线）
        ├── Plugin.php      ← 必需：插件元数据
        ├── icon.svg        ← 建议：商店图标
        └── ...
```

## Plugin.php 元数据

```php
<?php
declare(strict_types=1);

return [
    'code' => 'myplug',              // 必需，全局唯一
    'name' => '我的插件',
    'cat'  => 'pay',                 // 分类：pay支付 / template主题 / captcha验证 / login登录 / realname实名
    'description' => '插件功能说明…',
    'version' => '1.0.0',
    'author'  => '你的名字',
    'core'        => 0,              // 1=核心内置（不可卸载）
    'installable' => 1,              // 1=允许安装
    'status'      => 2,              // 默认状态 1启用 2停用
    'sort'        => 50,             // 排序，越小越靠前
    // 'config' => [...],           // 可选：后台可视化配置项（password 类型自动加密存入 sys_config）
];
```

## 分类约定

| 分类 | 约定文件 | 说明 |
|---|---|---|
| `pay` 支付 | `pay.php` | 支付发起 + 回调处理（统一入口 `api/pay_callback.php`） |
| `template` 主题 | `home.php` | 自定义公开首页（见主题开发指南） |
| `captcha` 验证 | — | 行为验证码（如 turnstile / geetest），启用时优先级最高 |
| `login` 登录 | `callback.php` 等 | 第三方登录（如 rainbow 彩虹聚合，绑定表 `rainbow_bind` 首次使用自动创建） |
| `realname` 实名 | — | 实名认证通道 |

## 框架 API（core/ 提供）

- `db()`：PDO 实例；`cfg($key, $default)`：读系统配置
- `e($s)`：HTML 转义输出；`json_out($code, $msg, $data)`：JSON 响应
- `plugin_scan()` / `plugin_enabled($code)`：插件扫描与启用状态
- `client_ip()`：真实 IP（CF-Connecting-IP → X-Real-IP → X-Forwarded-For）
- `sec_rate_hit($scene, $ip, $limit)`：限流计数；`audit(...)`：审计日志
- `csrfToken()` / CSRF 校验、`alert_add(...)`：告警中心

## 上传与调试

1. 整目录上传到 `网站根目录/plugin/`；
2. 后台「应用商店」刷新即可看到新插件，点击「启用」并「配置」参数；
3. 敏感配置（password 类型）自动加密迁移到数据库 `sys_config` 表；
4. `runtime/`、`uploads/` 保持可写。
