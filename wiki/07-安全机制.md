# 安全机制

## 接口安全

| 机制 | 说明 |
|---|---|
| 签名校验 | `api/license/verify` 支持 v2（HMAC-SHA256，签名串 `v2\n` + 各字段换行拼接）与 v1（MD5 兼容旧协议）；比较使用 `hash_equals` 防时序攻击 |
| 时间戳窗口 | 默认 ±10 分钟（`sign_time_window` 可配），超出拒绝 |
| nonce 防重放 | `api/auth.php`、`api/cloud_var.php` 私有读取均校验 nonce，窗口 2 倍时长内不可重复 |
| 限流 | 按场景独立计数：`license_verify` 120/分钟、`home_domain_query` 30/分钟、验证码 60/分钟、`auth` / `cloud_var` 阈值可配 |
| IP 封禁 | `ip_ban` 表 + `sec_ip_banned()` 全 API 前置检查 |

## 真实 IP 解析

默认开启：按 `CF-Connecting-IP → X-Real-IP → X-Forwarded-For` 顺序解析，自动过滤内网 / 保留地址，避免 CDN / 反代场景误伤。后台「验证与真实IP」面板可关闭。登录、注册、验证码、审计、封禁全链路生效。

## 账号与会话

- 密码 `password_hash` 加盐哈希；连续登录失败锁定（`login_fail` / `lock_time`）
- 身份证号等敏感字段加密存储
- 会话 Cookie `httponly + SameSite=Lax`；全站 CSRF Token 校验
- 输出统一 `e()`（`htmlspecialchars ENT_QUOTES`）转义

## 风控与追踪

- **多维黑名单**：设备码 / 卡密 / 域名三类，命中即拒绝并返回 `blacklisted`，同时写入告警中心
- **IP 封禁管理**：后台可手工封禁
- **防盗版追踪**（`piracy_track`）：异常使用行为留痕
- **验证日志**：每次 API 验证记录卡密、域名、设备、结果与失败原因
- **告警中心**（`core/Alert.php`）：黑名单拦截、签名失败等事件告警
- **审计日志**：后台敏感操作全留痕（`audit_log`）

## 数据安全

- 全量 27 表 InnoDB + utf8mb4，PDO 预处理语句杜绝 SQL 注入
- 支付回调独立入口 `api/pay_callback.php`，插件内自行验签
- AppSecret 后台脱敏展示；插件 password 配置项加密入库
- `config.php` / `install.lock` 安装后生成，含版权信息，勿公开泄露

## 验证码防退化

GD 产物做尺寸校验（正常 132×44 PNG 远大于 100 字节），任何退化产物自动降级 SVG；全部验证码响应带 `no-store` 头与精确 `Content-Length`，杜绝 1×1 空白图与缓存串扰。
