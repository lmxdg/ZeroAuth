ZeroAuth（云鉴权）是一套**原生 PHP 开发、轻量高效、高安全**的软件授权管理系统，为个人开发者、独立软件、桌面程序、APP 与源码产品提供：

- **软件卡密授权** —— 批量生成、限时 / 计次 / 永久
- **域名白名单授权** —— 绑定域名、首页授权状态查询
- **设备机器码授权** —— 一机一码、防多开滥用
- **云端在线校验** —— 防破解、防本地绕过、防重放

本系统无框架臃肿依赖，运行稳定、占用极低，适配所有主流虚拟主机 / 宝塔面板 / Linux 服务器。

## 功能特性

### 🔐 安全与风控

- **敏感数据加密**：实名信息、RSA 私钥等使用 AES-256-GCM 加密存储（兼容旧版 AES-128-CBC）
- **接口加密与签名**：支持 payload 加密请求体、HMAC-SHA256 v2 签名、RSA-2048 响应签名，SDK 可离线验签
- **防重放与限流**：nonce 原子化校验防并发重放，登录 / 注册 / 授权校验 / 验证码等场景基于 IP 的分钟级限流
- **二次验证**：管理端 TOTP（RFC 6238）动态口令，登录与安全中心可开启
- **多模式验证码**：Cloudflare Turnstile → 极验 4.0 → 内置 GD / SVG 图形码，自动降级
- **IP 风控**：IP 黑名单与全局封禁，CDN / 反代场景真实 IP 解析（Cloudflare、阿里云 CDN、Nginx 等，支持 IPv6）
- **审计追溯**：登录、授权、订单、财务、插件、配置等关键操作全量审计，管理员代登录留痕
- **盗版追踪**：盗版使用追踪与溯源

### 🗝️ 授权业务

- **应用与版本**：多应用 / 多版本管理，版本检查与更新包下载接口，支持强制更新
- **卡密授权**：批量生成、导出、绑定域名 / 设备、限时 / 计次 / 永久三种类型，支持续期、封禁、解绑
- **套餐与营销**：应用套餐、折扣活动、在线购买（易支付 / 支付宝 / 微信 / 余额支付）
- **订单与财务**：订单查询、支付回调、财务流水、提现审核
- **代理商体系**：多级代理商、等级规则、邀请码、分成结算、**邀请返利**（按订单实付比例自动返余额，幂等防重）
- **云变量**：按应用下发公开 / 私有变量，私有变量签名拉取，客户端可远程更新配置

### 🔌 开放接口

| 接口 | 说明 |
| --- | --- |

| `/api/auth.php` | 客户端鉴权 |
| `/api/get_secret.php` | 动态获取 AppSecret |
| `/api/cloud_var.php` | 云变量拉取 |
| `/api/public_key.php` | 公钥与加密参数下发 |
| `/api/order_status.php` | 订单状态查询 |
| `/api/app/version/check/` | 版本检查 |
| `/api/app/version/download/` | 更新包下载 |
| `/api/notice.php` | 授权站远程公告分发 |

### 📦 六语言 SDK

内置 **PHP / Java / Python / Go / Node.js / C++** 六语言 SDK 模板，统一实现 AppSecret 动态拉取、HMAC-SHA256 v2 签名与授权校验。后台「SDK 模板管理」支持按语言筛选与一键导出，导出时自动替换 `{{app_id}}`、`{{app_key}}`、`{{api_base}}` 并生成对应 README，每次导出写入下载日志。

### 🧩 插件与主题

- **商店拆分**：V2.2.0 起「应用商店」拆分为**插件商店**与**主题商店**两个独立入口，支持名称 / 标识 / 描述 / 作者 / 版本搜索与分类筛选，上传 `.zip` 包（≤50MB）自动解压安装；旧地址 `store.php` 自动跳转插件商店
- **文件驱动插件系统**：`plugin/*/Plugin.php` 放入即识别，后台「插件商店」安装 / 配置 / 启停 / 卸载
- **内置支付插件**：支付宝、易支付、微信、余额
- **验证码设置**：Cloudflare Turnstile、极验 4.0 的启用与密钥统一在「系统设置 → 验证码设置」配置
- **实名设置**：内置表单审核 + **腾讯云人脸核身**（H5 / 微信内活体刷脸，TC3-HMAC-SHA256 签名，证件号 AES 加密存储、前台脱敏展示），统一在「系统设置 → 实名设置」管理
- **短信与手机号注册**：支持对接**短信宝**、**赛邮 SUBMAIL** 网关发送短信验证码，注册页支持「邮箱 / 手机号」双通道（60 秒限频、验证码 10 分钟有效）
- **5 套首页主题**一键切换：默认、暗黑、极夜霓虹、渐变清新、极简商务
- **开发者文档**：后台「开发者」栏目内置《插件开发文档》《主题开发文档》，与随包文档实时同步

### 🧰 运营与运维

公告管理、工单系统（附件上传 ≤10MB、自定义分类）、邮件模板与场景通知、告警中心、数据报表、世界地图、IP 归属地（缓存 + 可关闭）、数据备份、健康检查、**检测更新与一键在线更新**（对接 GitHub Releases，发现新版本后进入 `update.php` 自动下载安装包、替换文件并自动清理，全程保护站点配置与自定义后台目录）、远程公告分发、**一键 / 定时跑路**（需二次确认，仅限弃用场景）

### 🖥️ 体验

三端（后台 / 代理商中心 / 用户中心）PC 与移动端响应式适配、深浅色模式、右上角灵动岛提示、品牌化安装向导与未安装引导页、彩色矢量图标。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| PHP | 8.0 ~ 8.2，需 PDO、PDO_MySQL、JSON、MBString；建议启用 cURL、Zip、OpenSSL、GD |
| MySQL | 5.6 ~ 5.7，字符集 `utf8mb4` |
| 目录权限 | 根目录与 `runtime/` 可写 |

## 快速开始

1. **下载部署**：克隆或下载本仓库，将全部文件部署到网站根目录；
2. **启动安装**：浏览器访问 `http://你的域名/install/` 进入品牌化安装向导；
3. **向导步骤**：环境检测 → 数据库配置 → 管理员账号 → 后台目录 → 执行安装；
   - 管理员账号、密码、后台目录名均可留空，系统自动生成安全值并在完成页展示；
4. **完成安装**：系统自动建表（29 张）、写入内置六语言 SDK 模板，生成 `config.php` 与 `install.lock`；
5. **开始使用**：登录后台 → 创建应用 → 发布版本 → 生成卡密 → 插件商店安装支付插件、系统设置配置验证码 / 实名 / 短信 → 导出 SDK 接入你的软件；
6. **升级**：后台「控制台 → 版本更新」发现新版本后点击「立即更新」一键在线升级；或覆盖升级，保留 `config.php`、`install.lock`、`runtime/`、`uploads/`，结构变更由 `core/schema_upgrade.php` 启动时自动迁移。

## 安全建议

- 安装完成后确认站点根目录已生成 `install.lock`，避免重复安装；
- 使用安装向导生成的**自定义后台目录名**，避免使用默认路径；
- 在「安全中心」开启 **TOTP 二次验证**；
- 按需在「系统设置」中开启或关闭 `trust_proxy_ip`（使用 CDN / 反代时建议开启）；
- 定期使用后台「数据备份」功能备份站点与数据库。
