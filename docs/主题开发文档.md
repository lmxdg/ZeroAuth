## 1. 主题是什么

官网首页（域名授权公开查询页）由「主题插件」渲染。主题本质上是 `cat = 'template'` 的普通插件，核心文件为 `home.php`。

## 2. 上传位置

```text
网站根目录/
└── plugin/
    ├── default/                ← 默认模板
    ├── tpl_v1/                 ← 营销模板
    ├── tpl_v2/                 ← 云服务模板
    ├── tpl_v3/                 ← 极夜暗黑模板
    ├── tpl_v4/                 ← 渐变清新模板
    ├── tpl_v5/                 ← 极简商务模板
    └── mytheme/                ← 你的主题
        ├── Plugin.php          ← 必需，cat 必须为 template
        ├── home.php            ← 必需，主题主文件
        ├── home.css            ← 可选
        ├── home.js             ← 可选
        └── icon.svg            ← 建议
```

- 将整个主题目录上传到 `网站根目录/plugin/`；
- 后台「应用商店 → 首页模板」中安装并启用；
- 访问站点根地址 `/` 即生效。

## 3. 优先级与互斥规则

1. `index.php` 扫描所有**启用中的** `template` 插件；
2. 按 `Plugin.php` 的 `sort` 数值升序选择，**数值越小优先级越高**；
3. 内置主题参考：`tpl_v2 = 8`、`tpl_v1 = 9`、`default = 10`、`tpl_v3 = 11`、`tpl_v4 = 12`、`tpl_v5 = 13`；
4. 在应用商店启用某个模板时，系统会自动停用其他已启用模板，避免冲突；
5. 若没有可用模板，首页返回「站点维护中」提示。

## 4. Plugin.php 元数据

```php
<?php
declare(strict_types=1);

return [
    'code'        => 'mytheme',
    'name'        => '我的主题',
    'cat'         => 'template',       // 必须
    'description' => '主题说明',
    'version'     => '1.0.0',
    'author'      => '你的名字',
    'core'        => 0,
    'installable' => 1,
    'status'      => 2,               // 1启用 2已安装停用 3未安装
    'sort'        => 5,               // 越小越优先
    'config'      => [
        [
            'key'   => 'announce_on',
            'label' => '显示顶部公告',
            'type'  => 'switch',
            'hint'  => '开启后在页面顶部显示公告条',
        ],
        [
            'key'   => 'footer_text',
            'label' => '页脚附加文字',
            'type'  => 'text',
            'hint'  => '显示在版权信息旁，如备案号',
        ],
    ],
];
```

配置项类型支持 `text / password / select / switch / textarea`，主题内读取：

```php
$announceOn = plugin_cfg_get('mytheme', 'announce_on', '0') === '1';
$footerText = plugin_cfg_get('mytheme', 'footer_text', '');
```

普通配置同时会合并进全局 `cfg()`，键名建议加主题前缀避免冲突。

## 5. home.php 渲染上下文

`index.php` 在 `require` 主题前已完成 DB 查询、限流与模板选择，以下变量 / 函数可直接使用：

| 变量或函数 | 说明 |
| --- | --- |
| `$query_domain` | 用户通过 `?q=` 提交的查询域名（已 trim） |
| `$result` | 查询结果：`['level' => 'ok'/'warn'/'bad', 'main' => '主文案', 'sub' => '详情']`，未查询时为 `null` |
| `$tplCode` | 当前主题的 `code` |
| `$tplDir` | 当前主题的实际目录名 |
| `base_url()` | 站点根 URL（含协议与主机） |
| `cfg('site_name')` | 站点名称 |
| `site_info($key)` | 站点信息（如 `site_info('keywords')`） |
| `site_logo_url('')` | Logo 地址 |
| `site_icon_url('')` | favicon 地址 |
| `site_meta_tags('')` | favicon + SEO meta 标签 |
| `site_contacts_html()` | 联系方式 HTML |
| `site_icp_html()` | 备案号 HTML |
| `e($str)` | HTML 转义 |
| `plugin_cfg_get($code, $key, $default)` | 读取主题配置 |
| `plugin_enabled($code)` | 判断插件是否启用 |

> `home.php` 由根目录的 `index.php` 引入，相对路径以**站点根目录**为基准。
> 引用主题资源请用 `<?php echo e(base_url() . 'plugin/' . $tplDir . '/home.css'); ?>`，
> 引用系统资源请用 `assets/...`，不要写 `../assets/...`。

## 6. 最小可用主题示例

```php
<?php
// plugin/mytheme/home.php
declare(strict_types=1);
$siteName = cfg('site_name', 'ZeroAuth');
$assetVer = '1.0.0';
?>
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title><?php echo e($siteName); ?> - 授权查询</title>
<?php echo site_meta_tags(''); ?>
<link rel="stylesheet" href="<?php echo e(base_url() . 'plugin/' . $tplDir . '/home.css?v=' . $assetVer); ?>">
</head>
<body>
<header class="my-header">
    <img src="<?php echo e(site_logo_url('')); ?>" alt="logo">
    <span><?php echo e($siteName); ?></span>
</header>

<form class="my-query" method="get" action="./">
    <input type="text" name="q" value="<?php echo e($query_domain); ?>"
           placeholder="请输入域名，如 example.com" maxlength="255">
    <button type="submit">查询授权</button>
</form>

<?php if ($result !== null): ?>
<div class="my-result my-result-<?php echo e($result['level']); ?>">
    <h3><?php echo e($result['main']); ?></h3>
    <p><?php echo e($result['sub']); ?></p>
</div>
<?php endif; ?>

<footer class="my-footer">
    <p>&copy; <?php echo date('Y'); ?> <?php echo e($siteName); ?></p>
    <?php echo site_contacts_html(); ?>
    <?php echo site_icp_html(); ?>
    <p>Powered by ZeroAuth · 原作者 APE开发项目组-玄猿工坊</p>
</footer>
</body>
</html>
```

## 7. 查询结果与限流

| `level` | 含义 | 建议配色 |
| --- | --- | --- |
| `ok` | 授权正常 | 绿色 |
| `warn` | 已过期 / 次数用尽 / 域名格式错误 | 橙色 |
| `bad` | 无记录 / 已封禁 / 查询失败 | 红色 |

- 首页查询按 IP 限流 **30 次 / 分钟**，超限时 `$result['level'] = 'bad'`，`$query_domain` 会被置空；
- 主题只需展示 `$result`，不要自行查询数据库或修改授权数据。

## 8. 静态资源与缓存

1. CSS / JS 建议与主题同目录，使用 `base_url() . 'plugin/' . $tplDir . '/...'` 引入；
2. 追加版本参数避免浏览器缓存，如 `?v=1.0.0`；
3. 需要缓存文件时写入 `runtime/`，不要写主题目录或根目录；
4. 图片建议使用 SVG 或 WebP，并压缩体积。

## 9. 移动端适配建议

- 必须包含 `viewport` meta；
- 使用 Flex / Grid 布局，避免固定像素宽度；
- 查询框在 ≤560px 时改为上下排列，按钮全宽；
- 导航在窄屏折叠或简化，点击区域高度建议 ≥44px；
- 结果卡片、页脚在窄屏单列展示，长文本 `word-break: break-word`；
- 使用系统彩色图标风格时，可直接引用 `assets/svg/*.svg`。

## 10. 安全规范

1. 所有输出使用 `e()` 转义，富文本需白名单过滤；
2. 不在 `home.php` 中写库或修改授权状态；
3. 自定义 AJAX 接口应放在主题目录独立文件，并引入 `core/bootstrap.php` 做鉴权与限流；
4. 不输出后台目录、数据库配置等敏感信息；
5. 保留页脚系统版权与原作者署名。

## 11. 上架检查清单

- [ ] `Plugin.php` 的 `cat` 为 `template`，`code` 全局唯一；
- [ ] `php -l Plugin.php`、`php -l home.php` 通过；
- [ ] 目录已上传至 `网站根目录/plugin/主题目录/`；
- [ ] 应用商店可安装、可配置、可启用；
- [ ] `$result` 三种 `level` 均有样式；
- [ ] PC 与移动端均无横向溢出；
- [ ] 资源路径使用 `base_url()`，不存在 404；
- [ ] 页脚保留版权署名。
