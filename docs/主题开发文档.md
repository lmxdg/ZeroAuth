适用版本：ZeroAuth V2.0.0+（内核 1.5.0）

## 1. 主题是什么

ZeroAuth 的官网首页（域名授权公开查询页）由「主题插件」渲染。**主题本质上是一个 `cat = 'template'` 的插件**，核心文件是 `home.php`。

## 2. 主题上传位置（重要）

```
网站根目录/
└── plugin/                    ← 主题统一上传到这个目录
    ├── default/               ← 默认官网模板
    ├── tpl_v1/                ← V1 营销官网模板
    ├── tpl_v2/                ← V2 营销官网模板
    └── mytheme/               ← ← ← 新主题上传/创建在这里
        ├── Plugin.php         ← 必需：主题元数据（cat 必须为 template）
        ├── home.php           ← 必需：主题主文件
        ├── home.css           ← 可选：主题样式
        ├── home.js            ← 可选：主题脚本
        └── icon.svg           ← 建议：商店图标
```

- 通过 FTP / 宝塔文件管理器 / SSH，把整个主题目录上传到 **`网站根目录/plugin/`** 下；
- 进入后台 **「应用商店」** 启用该主题插件；
- 访问网站首页 `https://你的域名/` 即生效。

## 3. 主题选择优先级规则

`index.php` 会扫描**所有启用中的 `template` 类插件**，并按 `Plugin.php` 中 `sort` **数值越小优先级越高**选取第一个可用的主题：

```php
// 内置主题 sort 参考
'default' => 10    'tpl_v1' => 9    'tpl_v2' => 8
```

因此：想让自己的主题优先生效，把 `sort` 设为小于当前启用主题即可（例如 `5`）；也可以直接停用其他主题。

## 4. Plugin.php 元数据

```php
<?php
declare(strict_types=1);

return [
    'code' => 'mytheme',
    'name' => '我的主题',
    'cat'  => 'template',            // 必须！主题类插件固定为 template
    'description' => '主题说明，展示在应用商店',
    'version' => '1.0.0',
    'author'  => '你的名字',
    'core' => 0,
    'installable' => 1,
    'status' => 2,
    'sort' => 5,                     // 数值越小，优先级越高
    'config' => [
        // 后台「应用商店 → 配置」可视化的配置项，参考 tpl_v1：
        [
            'key'   => 'announce_on',
            'label' => '显示顶部公告',
            'type'  => 'switch',
            'hint'  => '开启后在页面顶部显示公告条',
        ],
        [
            'key'   => 'footer_text',
            'label' => '页脚附加文字',
            'type'  => 'text',
            'hint'  => '显示在版权信息旁，如备案号',
        ],
    ],
];
```

配置项类型支持 `text / password / select / switch / textarea`，主题内用 `plugin_cfg_get('mytheme', 'key', '默认值')` 或 `cfg('key', '默认值')` 读取（普通配置已合并进全局 cfg）。

## 5. home.php 开发指南

### 5.1 环境变量与可用数据

`index.php` 在 `require home.php` 之前已完成：

| 变量/函数 | 说明 |
| --- | --- |
| `$query_domain` | 用户在 `?q=` 中提交的查询域名 |
| `$result` | 查询结果数组，结构：`['level' => 'ok'/'warn'/'bad', 'main' => '主文案', 'sub' => '详情文案']`；未查询时为 `null` |
| `base_url()` | 站点根 URL |
| `cfg('site_name')` / `site_info($key)` | 站点名称/SEO 等 |
| `site_logo_url('../')` | 站点 Logo 地址 |
| `site_meta_tags('../')` | favicon + SEO meta 输出 |
| `site_contacts_html()` | 联系方式（QQ/手机/邮箱/QQ群）HTML |
| `site_icp_html()` | 备案号链接 HTML |
| `plugin_cfg_get('mytheme', $key)` | 读取主题自身配置 |

> 注意：`home.php` 位于 `plugin/xxx/` 目录，引用静态资源请使用相对路径 `home.css` 或绝对路径 `base_url() . 'plugin/xxx/home.css'`；引用系统资源用 `../assets/...`。

### 5.2 最小可用主题示例

```php
<?php
// plugin/mytheme/home.php
declare(strict_types=1);
?>
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title><?php echo e(cfg('site_name', 'ZeroAuth')); ?> - 软件授权查询</title>
<?php echo site_meta_tags('../'); ?>
<style>/* 主题样式，或 <link rel="stylesheet" href="home.css"> */</style>
</head>
<body>
<header>
    <img src="<?php echo e(site_logo_url('../')); ?>" alt="logo">
    <span><?php echo e(cfg('site_name', 'ZeroAuth')); ?></span>
</header>

<!-- 授权查询表单：提交到首页 ?q= 参数即可，结果已由系统处理 -->
<form method="get" action="./">
    <input type="text" name="q" value="<?php echo e($query_domain); ?>" placeholder="输入域名查询授权状态，如 example.com">
    <button type="submit">查询</button>
</form>

<?php if ($result !== null): ?>
<div class="query-result query-<?php echo e($result['level']); ?>">
    <h3><?php echo e($result['main']); ?></h3>
    <p><?php echo e($result['sub']); ?></p>
</div>
<?php endif; ?>

<footer>
    <p>&copy; <?php echo date('Y'); ?> <?php echo e(cfg('site_name', 'ZeroAuth')); ?></p>
    <?php echo site_contacts_html(); ?>
    <?php echo site_icp_html(); ?>
    <!-- 版权声明：二开请保留 -->
    <p>Powered by ZeroAuth · 原作者 APE开发项目组-玄猿工坊 · 修改 MEMZ-LMXDG</p>
</footer>
</body>
</html>
```

### 5.3 查询结果的展示约定

| level | 含义 | 建议配色 |
| --- | --- | --- |
| `ok` | 授权正常 | 绿色 |
| `warn` | 过期 / 次数用尽 | 橙色 |
| `bad` | 无记录 / 已封禁 / 频率限制 | 红色 |

### 5.4 静态资源与缓存

- CSS/JS 建议与主题同目录（`home.css` / `home.js`），并在 URL 后拼接版本号强制刷新：`home.css?v=<?php echo e($meta['version'] ?? '1'); ?>`；
- 需要写缓存文件时写入 `runtime/` 目录（可写），不要写在主题目录内。

## 6. 安全与规范

1. 所有输出一律 `e()` 转义，防止 XSS；
2. 不要在 `home.php` 中执行写库操作（查询逻辑已由 `index.php` 完成）；
3. 自行新增 AJAX 接口请放入主题目录独立文件（如 `api.php`），并引入 `core/bootstrap.php` 做鉴权与限流；
4. 主题内不要输出后台目录路径等敏感信息；
5. **请保留页脚的系统版权信息（Powered by ZeroAuth 及原作者/修改者署名），二次开发请保留版权。**

## 7. 上架检查清单

- [ ] `Plugin.php` 的 `cat` 为 `template`，`code` 全局唯一，`php -l home.php` 通过；
- [ ] 目录已上传至 `网站根目录/plugin/主题目录/`；
- [ ] 应用商店中可见、可启用、可配置；
- [ ] `?q=` 查询结果三种 level 均有样式；
- [ ] 移动端自适应；
- [ ] 页脚保留版权署名。
