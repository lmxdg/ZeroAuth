## 〇、V2.0.0（内核 1.5.0）本次修复：验证码 1×1 空白图彻底解决

1. **修复 open_basedir（宝塔等环境）下验证码「乱码/空白」的问题**：
   - 根因：验证码绘制时探测字体路径（`/usr/share/fonts/...` 等）触发了 `is_file(): open_basedir restriction` Warning，该 Warning 文本被打印在 PNG 二进制数据**之前**，浏览器按 HTML 解析图片响应，表现为整页乱码或空白；
   - 修复：字体探测加 `@` 抑制；三个验证码入口统一**关闭错误回显**；PNG/SVG 输出前**清空全部输出缓冲**并附带精确 `Content-Length`，保证响应体是纯净的二进制图片；
   - 已在与您服务器相同配置（`open_basedir=/www/wwwroot/auth/:/tmp/` + `display_errors=1`）的模拟环境中验证：三端均输出纯净 PNG，零 Warning 混入。
2. **验证码全面改为 GD 生成（主路径）**：
   - GD 可用时始终由 GD 绘制并输出 132×44 PNG 验证码（干扰弧线/折线/噪点 + 随机倾角字符，无字体环境自动回退 imagechar 绘制）；
   - PNG 产物经输出缓冲捕获并做**尺寸校验**（正常 132×44 PNG 远大于 100 字节，历史 1×1 占位图仅 70 字节），任何退化产物都会被拦截并自动改走 SVG 兜底，代码层面不存在任何输出 1×1 空白图的路径。
2. **堵死「仍然看到旧 1×1 图」的缓存来源**：
   - 验证码所有响应（PNG / SVG / 限流占位图）统一增加 `Cache-Control: no-store` + `Pragma: no-cache` + `Expires: 0` + 精确 `Content-Length`，浏览器、CDN、反代均不再缓存验证码；
   - 全站 17 处验证码 `<img>` 与 JS 刷新地址统一追加 `?v=内核版本&t=时间戳` 双参数防缓存，旧缓存 URL 因带版本参数而必然失效。
3. 若覆盖升级后仍显示空白：**强刷浏览器（Ctrl+F5）**，并确认新版文件已覆盖到实际的后台目录（见下方升级提示）。

## 〇-1、V1.1.0（内核 1.1.3）历史修复

1. **修复验证码在部分环境显示 1×1 空白图片的问题**：
   - 根因：管理端验证码接口在服务器未安装 GD 扩展时，兜底输出了一张 1×1 透明 PNG 占位图；
   - 三端（用户/代理/管理）验证码入口统一为同一渲染管线：GD 可用输出 PNG，GD 缺失或绘制失败自动降级为 SVG 数字验证码；
   - 限流触发时返回「请稍后点击刷新」SVG 占位图。

> **升级提示（重要）**：本系统安装时会把 `admin/` 目录复制为您自定义的后台目录（如 `zaadmin/`）。在旧站点上覆盖升级本包时，除了覆盖根目录文件外，请**将新版 `admin/` 目录内的文件同步覆盖到您实际的后台目录**（尤其是 `captcha.php`），否则后台仍会运行旧版验证码代码。全新安装无需此操作。

## 二、修复

1. **修复前台登录验证码加载失败**：
   - 新增真实 IP 获取后，CDN/反代场景下验证码限流不再按代理 IP 误伤全站用户；
   - 验证码限流阈值 30 → 60 次/分钟；
   - 限流触发与无 GD 扩展时不再输出空白响应：无 GD 自动降级为 SVG 验证码（4 位数字，始终可用），限流时返回「请稍后点击刷新」占位图；
   - 前端验证码图片增加加载失败自动重试与时间戳防缓存。

## 三、新增

1. **真实 IP 获取**（默认开启）：按 `CF-Connecting-IP → X-Real-IP → X-Forwarded-For` 顺序解析真实客户端 IP（自动过滤内网/保留地址），登录、注册、验证码、审计、封禁等全链路生效；后台「验证与真实IP」面板可关闭；
2. **Cloudflare Turnstile 验证插件**（应用商店）：配置 Site Key / Secret Key 即可在三端登录、注册、找回密码、敏感操作等全部验证场景生效，启用时优先级最高；
3. **极验4.0 独立插件**：由系统内置功能拆分为独立插件（应用商店可配置 ID/Key），旧版本配置自动兼容迁移；
4. **注册验证码开关**：后台「系统配置 → 验证与真实IP → 注册验证码」可一键开启/关闭注册流程中的验证码（默认开启）；
5. **彩虹聚合登录插件**（应用商店 → 第三方登录）：
   - 支持文档全部 16 种登录方式（QQ/微信/支付宝/微博/百度/抖音/华为/小米/谷歌/微软/Facebook/钉钉/Line/Gitee/GitHub/GitLab）；
   - 支持未绑定账号自动注册、已登录账号一键绑定、绑定关系独立数据表 `rainbow_bind`；
   - 前台登录页自动展示已启用的第三方登录按钮；
   - 回调地址：`https://你的域名/plugin/rainbow/callback.php`。
6. 后台「应用商店」新增「行为验证」「第三方登录」分类筛选；
7. 首页模板选择升级：支持任意 `template` 类主题插件按 `sort` 优先级自动选择（详见主题开发文档）。
